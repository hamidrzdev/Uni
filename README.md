# کارگاه تمرین‌های CMP

اپ دسکتاپ Compose Multiplatform با رابط فارسی و تم روشن Material 3. سایدبار سمت راست برای فهرست تمرین‌ها آماده است و دو صفحهٔ تمرین «پردازش تصویر» و «عکس و هیستوگرام» دارد.

## اجرا

با JDK 21 و اتصال به Maven Central و Google Maven:

```powershell
.\gradlew.bat :composeApp:run
```

در Android Studio نیز می‌توان Gradle task `:composeApp:run` را اجرا کرد. برای اجرای تست‌های الگوریتم:

```powershell
.\gradlew.bat :composeApp:desktopTest
```

## رفتار تمرین تصویر

1. تصویر PNG، JPEG، BMP یا GIF انتخاب می‌شود. حداکثر حجم فایل ۳۰ مگابایت و حداکثر تعداد پیکسل ۲۰ میلیون است.
2. مقادیر خام ARGB به ترتیب سطرها در `IntArray` ذخیره می‌شوند. هشت مقدار نخست فقط برای پیش‌نمایش در رابط نشان داده می‌شود.
3. نسخهٔ خاکستری با میانگین صحیح `(R + G + B) / 3` ساخته و در باکس خروجی نمایش داده می‌شود. کانال شفافیت هر پیکسل حفظ می‌شود.
4. دکمهٔ «Smooth» فیلتر انتخاب‌شده را روی دادهٔ خاکستری اصلی اعمال می‌کند. فعلاً روش «میانگین‌گیر ۳×۳» موجود است. برای لبه‌ها نزدیک‌ترین پیکسل تکرار می‌شود تا پنجره همیشه ۹ نمونه داشته باشد.

الگوریتم و مدل تصویر در `commonMain` قرار دارند. انتخاب و خواندن فایل، تبدیل به تصویر قابل نمایش و پنجرهٔ برنامه در `desktopMain` هستند. این ساختار افزودن روش‌های پردازش و صفحه‌های تمرین بعدی را ساده نگه می‌دارد.

## تمرین ۲: عکس و هیستوگرام

1. از صفحهٔ «عکس و هیستوگرام» می‌توان با دکمهٔ «گرفتن عکس» یک تصویر از دوربین پیش‌فرض ثبت کرد؛ در صورت نبود دوربین یا ندادن مجوز، خطا در خود برنامه نشان داده می‌شود.
2. دکمهٔ «انتخاب فایل» همان فرمت‌های PNG، JPEG، BMP و GIF را به عنوان راه جایگزین می‌پذیرد.
3. پس از دریافت تصویر، برنامه نسخهٔ خاکستری را می‌سازد و هیستوگرام ۲۵۶ سطح روشنایی (از ۰ سیاه تا ۲۵۵ سفید) را به شکل نمودار نمایش می‌دهد. برای دیده‌شدن ستون‌های کم‌فراوان کنار یک ستونِ بسیار بزرگ، محور عمودی نمودار با مقیاس لگاریتمی رسم می‌شود؛ مقدار بیشترین فراوانی نیز جداگانه نمایش داده می‌شود.
